# Remzi Umra Travel Agency

## About the Project

Remzi Umra Travel Agency is a full-stack web application designed to help customers explore Umrah packages and access essential travel information through a user-friendly website.

## Features

- Explore available Umrah packages.
- Access essential Umrah travel information.
- Responsive and user-friendly interface.
- Administrative dashboard for managing the system.

## Technologies Used

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **ORM:** Prisma

## Getting Started

To run this project locally:

1. Clone the repository.
2. Install the dependencies for the frontend and backend.
3. Configure your environment variables.
4. Set up the database.
5. Start the backend and frontend development servers.
